# Week 6 — Own your stack

The final bootcamp session. First hour, everyone installs this library and gets one real
thing out of it before they leave. Second hour, how agents actually work, how to build
your own, and how to troubleshoot when one breaks.

This folder holds the material that has to stay in sync with the library itself, so the
page and the repo cannot drift apart. When a skill is added or the install steps change,
it changes here first.

| File | What it is |
|---|---|
| `INSTALL-PAGE-COPY.md` | The install section as it should read on the site. Verified by running it |
| `AITOOLS-REDESIGN.md` | What is being designed on the AI tools and skills page, and why |

## The three things Week 6 has to land

1. **Installed and producing.** Not "here is what it could do." Something real on their
   own laptop before they leave the room.
2. **The skill behind the skills.** What an agent is, how to build one, how to fix it.
   Teaching them to fish, not handing them a fish.
3. **Autonomy without recklessness.** The new `safe-autonomy` skill is the Week 6 close.
   Every agent who gets fast at this eventually turns the permission prompts off. The
   session is where they learn to do it with the stops in place instead of finding out
   the hard way six weeks later.

## Standing rules for this folder

- **Verified means someone ran it.** Every instruction here was executed on a real
  machine before it was written down, with the date and the Claude Code version noted.
  Anything not yet run gets labeled unverified rather than quietly shipped.
- **Counts are checked, not remembered.** The skill count on the page comes from counting
  `plugins/realtor-skills/skills/*/SKILL.md`, every time it is written.
